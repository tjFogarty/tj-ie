Swatcher is still a free application to explore paint colours available in Ireland, but has been rebuilt for a better dev experience.

## Key Features

### Laravel

The latest version of Laravel powers 2.0. It's hosted on Laravel Cloud, and comes with a wide ecosystem of packages to aid in development.

Inertia is also used, along with SSR to improve SEO.


### New Design

It looks more like a sleek catalogue now, with some fun little features in there to encourage play and exploration.

### Refreshed Features

Features have been simplified and improved. For example, paints that work well together are categorised along with explanations, along with the paint matching being improved.

Some older, unused features have been stripped out. Features that haven't been ported over yet are getting more consideration when it comes to design and placement.
